# 闪记 FlashNote · 截屏记账

付款后截图 → 粘贴进 App → 确认识别结果 → 自动汇总周/月账单。纯本地运行，数据不上传任何服务器。

## 怎么运行

**方式一（最简单）**：直接双击 `index.html`，用浏览器打开即可。

**方式二（推荐，手机上用）**：在本目录起一个本地服务，手机和电脑连同一 Wi-Fi 后用手机浏览器访问：

```bash
# 在 shanji/ 目录下执行任意一种：
python -m http.server 8742
npx serve .
```

- 电脑访问：http://127.0.0.1:8742
- 手机访问：http://<电脑局域网IP>:8742
- 手机浏览器「添加到主屏幕」后，体验接近原生 App。

首次启动会自动载入约 80 笔演示数据（可复现），在「我的 → 清空全部数据」一键清空后即为全新账本。

## 功能清单

| 模块 | 功能 |
|---|---|
| 明细 | 月切换、月度支出/收入/结余、按天分组流水、截屏来源标记、点击编辑/删除 |
| 截屏记账 | 粘贴（Ctrl+V）/ 拖拽 / 点击上传付款截图 → 自动压缩存档 → 确认金额、商户、时间、分类、备注 → 保存；未保存的截图在明细页顶部有「待确认」提醒条，不丢 |
| 统计 | 周/月切换、总支出与环比（少花绿 / 多花琥珀）、近 5 月趋势柱状图、分类占比进度条、规则引擎生成的消费洞察（咖啡/外卖/环比） |
| 我的 | 累计笔数与收支、导出 JSON 备份、载入演示数据、清空数据 |
| 数据 | 8 个分类（餐饮/交通/购物/日用/娱乐/医疗/学习/其他）、支出收入双类型、localStorage 持久化、脏数据容错、隐私模式自动降级为会话内存 |

## 架构（三层）

```
index.html / css/style.css        视图层：设计稿 1:1 还原（暖灰分层 + 紫/绿/琥珀）
js/app.js                         视图控制：渲染、交互、识别流程编排
js/ledger.js          业务层：月/周汇总、环比、趋势、分类占比、消费洞察规则（纯函数）
js/store.js           数据层：数据模型与校验、localStorage 存取、演示数据种子
```

依赖：零依赖、零构建。金额全部以「元 × 2 位小数」规范化存储，截图压缩到 360px 宽 JPEG 后随账单存档。

## 已知边界与扩展点

- **识别方式**：Web 环境无法做系统级「截屏自动唤醒」，当前是「截图 → 粘贴/上传 → 表单确认」的等价流程，字段需手动确认。
  - 想要真 OCR：可在 `app.js → handleShotFile` 后接 Tesseract.js（离线、中文包约 15MB）或云端视觉大模型，把识别出的金额/商户预填进表单即可，表单结构已就位。
- **多端同步**：数据层接口（add/update/remove/getAll/exportJSON/importAll）稳定，日后加一个 Spring Boot 后端替换 Store 内部实现即可，业务层与 UI 无需改动。
- 测试脚本 `tests/e2e.cjs` 中的 `page.once('dialog')` 依赖原生 confirm，若替换为自定义弹层需同步改测试。
