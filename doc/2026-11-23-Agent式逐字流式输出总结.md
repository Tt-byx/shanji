# Agent 式逐字流式输出总结（2026-11-23）

## 用户的问题
流式输出要参考 `C:\Users\28182\Desktop\Agent` 项目的效果来做（上一版是"分段蹦"，用户看过 Agent 项目后要求对齐它的观感）。

## 如何分析的
用 Explore 子代理调研 Agent 前端（Vue）的流式实现，提炼出四个效果要件：
1. **SSE 逐 token 连续流出**：`fetch('/api/chat/stream')` + `resp.body.getReader()` 按 `token` 事件 `full += data; onToken(data)` 增量追加——不是分段蹦，是连续小步；
2. **尾部闪烁光标**：`message.streaming` 时追加 `▍`，CSS `animation: blink 1s step-end infinite`（生成中亮灭提示）；
3. **AI 回复无气泡**（透明背景直接落页面）——我们 v1.7 已实现 ✓；
4. **自动粘底滚动**：消息列表内容变化后 `scrollTop = scrollHeight` 跟随到底部。
后端为标准 SSE（`token/done` 事件），与我们 chunked 逐 delta 的网络层等价，无需改服务端。

## 如何解决的
对照四要件改造 ChatScreen（v1.9，versionCode 10）：
1. **节拍器从"分段蹦"改为"连续小步流出"**：删掉 segmentEnds 切段器，进度状态 `typedChars`（bubbleId→已流出字符数，页面级 SnapshotStateMap 不丢进度）；每 25ms 推进 `剩余字符.coerceIn(1,4)` 字——剩余多时 160 字/秒、收尾渐慢到 1 字/25ms，模拟 token 连续吐出且掩盖 flash 模型过快；
2. **ChatItem 加 `streaming` 标志**：新气泡创建时 true（所有流式创建点），全部完成路径（成功/act首轮/空回复/失败）置 false；生成中尾部拼 `▍`，独立 LaunchedEffect 每 500ms 亮灭一次（Agent 同款 blink 节奏）；
3. **粘底滚动**：新增 `LaunchedEffect(lastGrowLen)`——内容流出增长时，仅当视口贴着底部（最后一条可见）才跟随滚动，用户上翻读历史不打断；条数变化（新消息）仍强制滚到底；
4. 历史消息 `streaming=false` 初始化即全文，不重播流出动画；服务端零改动。
