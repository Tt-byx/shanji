# M1 地基模块小结（2026-11-21）

## 用户的问题
按已批准的二期实施计划执行 M1 地基模块：Room 数据库迁移（含 tx.json 存量数据迁移）、备份导出/恢复、深色模式三态、应用密码锁（BiometricPrompt 指纹/人脸 + PIN 降级），每步跑端到端测试（MuMu + adb），并沉淀客户端测试方法。

## 如何分析的
- 代码侧：`TxStore` 对外 API（txs/add/update/remove/clear/replaceAll/exportJson/seedDemo）被 8 处 UI 引用 → 采用"保持 API 不变、内部换 Room"的低风险迁移；`Tx` 领域模型与 `Ledger` 纯函数层零改动。
- 环境侧：摸清三个关键坑——
  1. 沙箱会在命令结束时回收子进程（Docker/MuMu/adb server 都受影响）→ 常驻程序由用户手动启动，adb 每条命令先 `connect`；
  2. PowerShell `>` 重定向会破坏二进制 → 截图用 `shell screencap` + `pull`；
  3. Docker Desktop 手动代理（127.0.0.1:8888）导致容器拉依赖失败/aliyun 502 → 仓库顺序调整为 google/mavenCentral/pluginPortal 在前、aliyun 兜底。
- 测试侧：项目零测试基础且构建全在 Docker 内，Compose androidTest 反连 adb 成本过高 → 采用 `uiautomator dump`（节点文本断言）+ `screencap`（截图人工核验）方案。

## 如何解决的
1. **M0**：`git init` 基线提交（含 .gitignore 排除 build 产物）；Git Bash 跑 build.sh（WSL bash 缺 cygpath）；MuMu 用 `MuMuManager control -v0 launch` / 用户手动启动后 `adb connect 127.0.0.1:16384`。
2. **依赖**：KSP 2.0.21-1.0.28 + Room 2.6.1 + biometric 1.1.0 + fragment-ktx，schema 导出到 `app/schemas/`。
3. **数据层**：新建 `data/db/TxEntity/TxDao/AppDatabase`（预留 updatedAt/deleted/dirty 同步列）；`TxStore` 内部改 Room（runBlocking 写 + Flow 收集回写 StateList）；`migrateLegacyFile()` 一次性导入 tx.json 后改名 `.bak`，导入视作已播种。
4. **备份**：`BackupManager`（JSON 解析 + CSV 生成带 BOM）；ProfileScreen 增 导出 CSV / 恢复备份（SAF 选择 + 覆盖确认弹窗）。
5. **深色模式**：`Theme.kt` 增 DarkScheme 与 ThemeMode 三态（Snapshot state 驱动重组）；全项目清理 `Color.White`/`Bg`/`BorderSubtle` 等硬编码色改走 MaterialTheme。
6. **应用锁**：`LockManager`（PBKDF2 加盐存 prefs、会话解锁态）+ `ui/LockScreen.kt`（生物识别优先、PIN 数字键盘兜底、满位自动校验）；MainActivity 改 `FragmentActivity` 并在 setContent 外层加锁判定；ProfileScreen 增应用锁开关。

**给用户的客户端 E2E 测试教学要点**：
1. 连接：`& "D:\Program Files\Netease\MuMu\nx_main\adb.exe" connect 127.0.0.1:16384`（每条命令先连，adb server 会被回收）
2. 装包：`adb install -r apk\ShanJi-v1.2-debug.apk`；清环境：`adb shell pm clear com.shanji.app`
3. 断言：`adb shell uiautomator dump /sdcard/ui.xml` + `pull` 后用正则查节点文本（比坐标点击稳定）
4. 截图：`adb shell screencap -p /sdcard/shot.png` + `pull`（**不要用 PowerShell `>` 直接重定向**，会损坏二进制）
5. 交互：坐标点击 `input tap`、输入 `input text`（仅 ASCII，中文需另想办法）、返回 `input keyevent 4`

**遗留/风险**：真机补测生物识别；一次错误 PIN 测试出现偶发竞态（复测两次行为正确，后续模块留意）；Docker 代理与 aliyun 502 问题已绕过但根因在本机代理规则。
