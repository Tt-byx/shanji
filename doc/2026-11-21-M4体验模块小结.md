# M4 体验模块小结（2026-11-21）

## 用户的问题
按实施计划执行 M4 体验模块：搜索、日历视图、周期记账、桌面小组件，完成后在 MuMu 跑 E2E。

## 如何分析的
- 导航：项目用手工 tab 状态（无 navigation 库），新增子页面沿用 `screen` 字符串分支 + 返回回调，不引入新依赖。
- 搜索：数据量千级以内，直接内存过滤 StateList（比走 DAO 查询更简单，无需 debounce 复杂度）。
- 日历：纯 UI（自绘日期网格），数据复用 `Ledger.monthTx` 按日聚合。
- 周期记账：按计划取舍"App 启动时补记"（不依赖 WorkManager/后台任务），规则读取用 `dao.listEnabled()` 直接读库，绕开 Flow 加载时机问题。
- 小组件：RemoteViews 不能查 Room → "摘要快照"方案（写库后把 本月/今日支出、预算 写 SharedPreferences，Provider 读快照渲染）；且快照计算**必须直接读库**（首次实现读 StateList 导致全 0，因为 init 时 Flow 尚未 emit——实测发现后修复）。

## 如何解决的
1. `SearchScreen`（返回键 + 结果计数 + 复用 `TxRow`，TxRow 改 internal）。
2. `CalendarScreen`（月导航、每日支出底色深浅、今日描边、点日期弹当日明细 ModalBottomSheet）。
3. 周期记账：`RecurringEntity/Dao` + `MIGRATION_3_4`（DB v4）+ `RecurringStore` + `RecurringScheduler.checkAndRun()`（AppStore.init 时执行）+ `RecurringScreen`（启停 Switch、增删改对话框）。
4. 小组件：`widget_summary.xml` + `widget_bg.xml` + `widget_info.xml` + `ShanjiWidgetProvider` + `WidgetUpdater`（快照读库）+ Manifest receiver；所有写路径（TxStore/BudgetStore 变更）调 `AppStore.notifyChanged()`；versionCode 升 4（v1.3）。
5. 顺手修复：系统返回键直接退出 App → 加 `BackHandler`（search/calendar/recurring 返回上级）。

**测试环境经验（沉淀）**：
- MuMu 桌面是 Lawnchair：长按空白 → "微件" → 闪记 → 拖拽预览到桌面（单次连续 `input swipe` 长按拖动可成功）。
- `uiautomator dump` 与 `screencap` 偶发不同步（screencap 返回旧帧）：断言以 dump 文本为准，截图连续拍两张取新帧。
- 底部导航图标节点 content-desc 为空，断言用 text="截屏"。
- 系统 `APPWIDGET_UPDATE` 广播受保护无法从 shell 发送（预期行为）。

**遗留**：周期记账局限"不打开 App 不生成"已在 UI 注明；小组件点击跳转暂未接（默认 launcher 行为）；`updatePeriodMillis=30min` 兜底刷新。
