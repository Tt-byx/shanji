# 2026-11-22 AI 差异化功能开发总结

## 用户的问题

1. 想做记账 App 的 AI 差异化，先调研 GitHub/网络上客户端交互和产品，再规划功能；
2. 调研三个梯队全部实现（排除 MCP 和游戏化存钱）；
3. AI 调用走服务器中转（服务器持 key），语音记账要做；
4. 模型用 DeepSeek：`deepseek-flash`（用户给的 v4.1flash 不是有效模型名，实测 API 返回支持的是 `deepseek-flash` / `deepseek-v4-pro`，选用 deepseek-flash）。

## 如何分析的

1. **调研**：网络检索 AI 记账产品（Cleo、Rocket Money、BeeCount、Claude 个人财务等），产出 `doc/2026-11-21-AI差异化功能调研总结.md`，分三梯队；
2. **规划**：Explore 子代理摸清安卓端（AiRecognizer/Room/Ledger/ApiFactory）与后端（Controller/ApiResponse/JWT/Flyway）现状，Plan 子代理产出实施方案，经用户批准（`.trae/documents/AI差异化功能全量实现.md`）；
3. **分 6 阶段实施**，每阶段可独立构建验证；错误统一走 `SyncManager.friendlyError` 人话化单点。

## 如何解决的

### 后端 shanji-server（新增 ai 包，无 Flyway 迁移）
- `AiController`：`POST /api/ai/parse`（一句话记账解析）、`/api/ai/chat`（对话+function calling）、`/api/ai/insight`（洞察/月报文案）；JWT 认证沿用现有链路；
- `AiService`：Spring RestClient 调 chat/completions，配置 `GLM_API_KEY/GLM_BASE_URL/GLM_MODEL`（DeepSeek 兼容 OpenAI 协议），信号量 2 并发护内存，max_tokens 2000（推理模型 reasoning 计长），JSON 抠取+重试一次，错误全部翻成人话（"AI 还没配置好"/"AI 忙不过来"等）；
- 分类 key 与安卓端对齐（dining/transport/shopping/daily/entertainment/health/education/other），few-shot 示例保证"午饭 15 块"→dining。

### 安卓 shanji-android（新增 4 文件 + 改 7 文件）
- `data/net/AiApi.kt` + `data/AiClient.kt`：Retrofit 接口（70s 读超时）+ 统一过 friendlyError；
- **一句话记账**（RecordSheet）：弹层顶部输入行，AI 解析回填金额/商户/分类，复用现有"保存这笔账单"入库，不直接写库；
- **语音记账**（`ui/VoiceInput.kt`）：系统 SpeechRecognizer，Manifest 加 RECORD_AUDIO，运行时权限申请，转写回填同一输入行；
- **自动分类学习**（`data/CategoryLearner.kt`）：SharedPreferences 存 商户→分类，保存时学习、解析时优先于 AI 建议，非法 key 兜底；
- **对话查账**（`ui/ChatScreen.kt`，首页 AI 图标进入）：GLM 出 `queryTx` 动作 → 安卓查 Room → 结果回传二次请求生成自然语言；`addTx` 动作打开记账弹层预填（不直接写库）；
- **AI 洞察卡**（StatsScreen）：规则命中交 AI 改写成人话，失败降级现有规则文案；
- **月度报告**（StatsScreen"上月总结"）：`MonthlyReportStore` 按月缓存，重复查看不调 AI；
- **人设**（AI 识别设置新增"说话风格"：默认/温和/毒舌）：存 `ai_persona`，作 system prompt 前缀。
