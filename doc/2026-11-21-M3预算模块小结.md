# M3 预算模块小结（2026-11-21）

## 用户的问题
按实施计划执行 M3：月度总预算 + 分类预算 + 超支提醒（轻量版：应用内横幅/标红/Toast，不做后台通知），完成后在 MuMu 跑 E2E。

## 如何分析的
- 数据结构走最小方案：`budgets` 表一行一个预算（id 字面量 `total` / `cat_dining`），月度循环不做按月快照（大学生场景够用）。
- 计算层保持纯函数风格：新建 `BudgetCalc.kt`（spentTotal/spentOf/progress/justCrossed），与 `Ledger` 并列，方便复用与验证。
- 提醒分三处：统计页预算卡（超支标红）、首页超支横幅、记账保存时"刚越过预算"Toast（`justCrossed` 只在 old≤budget<new 时触发，避免每次记账都弹）。

## 如何解决的
1. 数据层：`BudgetEntity/BudgetDao`、`MIGRATION_2_3`（DB v2→v3 建表）、`AppDatabase` 升 v3；`BudgetStore`（Room+Flow，`set()` amount≤0 即软删）挂到 `AppStore`。
2. UI：
   - `ui/BudgetCard.kt`：总预算 + 各分类预算行（LinearProgressIndicator，超支红、剩余绿），`LinearProgressIndicator` 用新式 lambda progress API。
   - `StatsScreen` 月视图页头下插入 `BudgetCard`。
   - `ProfileScreen` 新增"预算设置"菜单 → 滚动对话框（总预算 + 8 分类金额，留空=不设）。
   - `HomeScreen` 月度概览卡下方插入超支横幅（红底提示超支金额）。
   - `RecordSheet` 保存时计算 justCrossed 并 Toast（注意：`LocalContext.current` 必须提升到 composable 作用域，不能在 onClick lambda 里调用）。
