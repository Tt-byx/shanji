# 闪记二期实施总结（2026-11-21）

## 用户的问题
用户自研的安卓记账软件（半成品）希望全面完善：先上网调研记账软件功能清单，随后授权自由发挥实施——约束为：个人开发者（登录用账号密码等可行方案）、只做安卓手机端、计划加后端、功能面向大学生实用（不要多币种/信用卡/净资产）、暂不做社交共享；每完成一个模块跑端到端测试（MuMu 虚拟机，用户首次接触客户端测试，要求教学）；有问题随时确认。

## 如何分析的
1. **功能调研**：网络检索 GitHub 开源项目（Actual Budget、Firefly III、MMEX、Ivy Wallet、Cashew）与商业产品（随手记、挖财），输出 9 类功能清单，与用户确认范围（剔除多币种/信用卡/净资产/社交）。
2. **代码摸底**：项目为 Kotlin + Compose、数据存 tx.json、无数据库无测试；识别出最大风险点——`TxStore` 被 8 处 UI 直接引用 → 采用"保持对外 API 不变、内部换 Room"的低风险迁移；同时发现 `Ledger.summary` 把非支出算进收入的既有 bug（M2 修复）。
3. **关键决策（均与用户确认）**：登录=账号密码（DTO 预留验证码通道）；后端=Spring Boot + MySQL + Docker Compose（用户熟练栈）；密码锁=BiometricPrompt+PIN 兜底；测试=adb + uiautomator（项目零测试且构建全在 Docker 内，Compose androidTest 反连成本过高）。
4. **分 7 个阶段实施**（M0 环境 → M1 地基 → M2 多账户 → M3 预算 → M4 体验 → M5 后端 → M6 登录同步），每阶段：改代码 → Docker 构建 → 装 MuMu → 跑用例 → 截图/dump 取证 → 写 doc 小结 → git 提交。

## 如何解决的
- **环境类**：沙箱会回收命令子进程（常驻程序由用户手动启动、adb 每条命令先 connect）；PowerShell `>` 损坏二进制（截图改 screencap+pull）；Docker 手动代理 127.0.0.1:8888（Clash Verge）多次停机挡网络（多次与用户确认处理）+ aliyun 源 502（Gradle 仓库调整顺序）；build.sh 需 Git Bash（WSL bash 缺 cygpath）。
- **M1**：Room v1 + `migrateLegacyFile`（tx.json→Room，改名 .bak，导入视作已播种）；SAF 备份 JSON/CSV（utf-8-sig）；Theme 三态 + 全项目硬编码色清理；BiometricPrompt + PIN 键盘兜底。
- **M2**：`MIGRATION_1_2`（accounts 表 + txs 加列 + 4 默认账户）；转账用 `type=transfer + accountId/toAccountId`（不建表）；修 summary 口径；第 5 个「账户」tab。
- **M3**：budgets 表 + `BudgetCalc` 纯函数 + 统计页预算卡 + 首页超支横幅 + 记账 Toast（`justCrossed` 只在越界瞬间触发）。
- **M4**：搜索（内存过滤+复用 TxRow）、自绘日历热力图、周期记账（v4 表 + 启动补记调度器）、桌面小组件（RemoteViews 摘要快照方案，**读库而非 StateList**（首版全 0 的 bug 实测发现）、记账后实时刷新）；顺手加 BackHandler。
- **M5**：`shanji-server` 完整工程（JWT/BCrypt/Flyway/软删/LWW push-pull），踩坑依次修复：构造函数重复、allowPublicKeyRetrieval、TINYINT vs INTEGER、嵌套 Repo 不被扫描、HQL 实体名、（与 M6 联调）null 列默认值。
- **M6**：Retrofit+kotlinx 网络层、SyncManager（push→pull→LWW→清 dirty→记水位）、**软删墓碑**（防 pull 复活删除）、登录页（服务器地址+测试连接）、Profile 登录卡；联调修复 `encodeDefaults=false` 导致 accountId 缺失的 500。
