# 注册返回 400 问题排查总结（2026-11-21）

## 用户的问题
App 内"测试连接"成功（`/api/health` 通），但点"注册"返回 400。需要定位原因并修复。

## 如何分析的
1. **查服务器日志**：无 register 相关错误（`GlobalExceptionHandler` 对参数校验失败不打日志，只回 JSON message），仅见一条无关的 TLS ClientHello 解析告警（有人用 https 访问 http 端口）。
2. **多场景复现服务端**（curl 直连 `x.x.x.x:8080`，公网 IP 已隐去）：
   - 正常注册 `probe_ok1` → **200**
   - 中文用户名"测试用户" → **200**（排除编码问题）
   - 用户名 `ab`（2位）→ **400** `username size must be between 3 and 64`
   - 密码 `123`（3位）→ **400** `password size must be between 6 and 64`
3. **结论**：服务端完全正常，400 是 Bean Validation 参数校验——**用户名少于 3 位或密码少于 6 位**。根因在客户端：`LoginScreen.submit()` 只校验了"用户名非空 + 密码≥6"，**漏了用户名≥3 位**，非法请求发出去被服务端 400 拒绝，且用户看到的是英文校验文案。

## 如何解决的
修改 `LoginScreen.submit()` 提交前校验（对齐服务端规则，全部中文提示）：
- 用户名为空 → "请输入用户名"
- 用户名 <3 字符 → "用户名至少 3 个字符"
- 密码 <6 位 → "密码至少 6 位"

重新构建 APK（同步更新 `apk/ShanJi-v1.2-debug.apk` 与 `闪记-服务器版-20261121.apk`），模拟器安装后实测：输入 2 位用户名点注册 → **客户端直接拦截显示"用户名至少 3 个字符"，不再发请求**。

## 最后结果
- 原因确认：400 = 用户名/密码长度不满足服务端校验（非网络、非服务端故障）
- 客户端修复完成并验证 PASS；最新 APK 已就位（用户需重新覆盖安装）
- 服务端无需改动（复现证明其行为正确）

**给用户的直接答案**：注册时用户名至少 3 个字符、密码至少 6 位；装最新 `闪记-服务器版-20261121.apk` 后会得到中文提示。
