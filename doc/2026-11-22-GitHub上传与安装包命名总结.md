# GitHub 上传与安装包命名总结（2026-11-22）

## 用户的问题
1. 要把整个项目上传到 GitHub；
2. 安装包命名不正确——已经是 release 包了，文件名却还叫 `ShanJi-v1.2-debug.apk`（"德不孤包"=debug 包），要求改成正确的名字。

补充确认（问答弹窗）：
- 仓库结构：**合成一个仓库**（原 shanji-android / shanji-server 两个独立 git 仓库合并）；
- 可见性：**Public 公开**，但要求**隐私信息隐藏**。

## 如何分析的
1. **摸底仓库现状**：根目录不是 git 仓库，`shanji-android`、`shanji-server` 各有独立 `.git`（各有一段提交历史）；`gh` 已登录（Tt-byx）。
2. **全仓隐私扫描**（正则匹配 API key / 公网 IP / 测试账号 / SSH 密钥路径）：
   - 代码：`ApiFactory.DEFAULT_URL` 含公网 IP `101.200.178.158`；README 含测试账号 `e2euser / pass123456`；
   - 文档：`doc/` 下 4 个总结含公网 IP、SSH 密钥路径、测试账号；
   - 服务器：`application.yml` 的 AI key 走环境变量 `${GLM_API_KEY:}`，未入库（安全）；但 `shanji-server/.env` 含数据库/JWT 开发密码；
   - **子仓历史**中也含公网 IP——直接推历史等于没脱敏，因此决定**扁平化为单次初始提交**（历史随嵌套 `.git` 一并移除）。
3. **大文件扫描**：发现 `shanji-android/sdk/` 下 4 个 SDK 压缩包共约 290MB（cmdline-tools 153MB 等），绝不能入库；APK 产物也应排除。
4. **嵌套 git 处理**：根目录 `git init` 后删除两个子目录的 `.git`，全部内容并入根仓库。

## 如何解决的
### 1. 安装包命名修正
- `ShanJi-v1.2-debug.apk` → **`ShanJi-v1.4-release.apk`**（与 versionName 1.4 对齐）；
- 删除重复旧包 `闪记-服务器版-20261121.apk`（同内容同时间戳的副本）；
- `build.sh` 产物路径、`README.md` 全部引用同步改为 release 名；README 中"debug 签名"字样改为"release 签名"；
- `ShanJi-v1.0/v1.1-debug.apk` 是真正的历史 debug 包（16MB），名字无误，保留。

### 2. 隐私脱敏（Public 前置）
- `ApiFactory.DEFAULT_URL`：公网 IP → `http://192.168.1.100:8080/`（局域网占位；手机上已在登录页设置过服务器地址的不受影响，prefs 优先于默认值）；
- README：删除测试账号，改为"账号在登录页自行注册"；
- `doc/` 4 篇总结：公网 IP → `x.x.x.x`（已隐去）、SSH 密钥路径/测试账号 → 描述性文字；
- 确认 DeepSeek API key **从未进入**任何文件（全仓扫描无匹配）。

### 3. 合并为单仓库并推送
- 新建根 `.gitignore`：排除 `.screenshots/`、`.trae/`、`.workbuddy/`、`*.apk`、`*.aab`、构建产物、`shanji-android/sdk/`、`.env`、`*.pem`、`*.jks`、override 文件等；
- 删除 `shanji-android/.git`、`shanji-server/.git`；
- `git init` → `git add -A` → 校验（134 个文件、无 >5MB 文件、`git grep` 隐私正则零匹配）→ 单次初始提交；
- `gh repo create shanji --public` 推送成功；`git gc --prune=now` 清掉首次 add 遗留的 257MB 松散对象。

## 最后结果
- **GitHub 仓库**：https://github.com/Tt-byx/shanji （Public，134 个文件，隐私扫描零残留）；
- **安装包**：`apk/ShanJi-v1.4-release.apk`（2.3MB release 包），`build.sh` 以后产物固定为该命名；
- 本地根目录成为唯一 git 仓库，嵌套子仓已移除，大小已 gc 清理至 0 松散对象。

**遗留提示**：
1. 手机端服务器地址若一直用默认值（从未手动设置过），下次装新包需在登录页把地址设回真实服务器 IP；
2. 服务器 JWT_SECRET / 数据库密码仍是开发默认值，公网长期运行建议更换（仓库内 `docker-compose.yml` 仅含默认值，真实值放 `.env` 不入库）；
3. 仓库暂无根 README（各子目录自带 README），需要的话可再补一份总览。
